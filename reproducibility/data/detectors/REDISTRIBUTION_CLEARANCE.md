# Redistribution clearance for detector context files

Reviewed 2026-08-25.  This file records the redistribution terms verified for
the three detector data files retained in this directory.  Source URLs,
retrieval dates, and SHA-256 hashes are documented in `README.md`; the local
copies were re-verified against those hashes on the review date.

## `BBO_PLIS_Schmitz2021.dat` — cleared (CC-BY-4.0)

The source Zenodo record, K. Schmitz, *New Sensitivity Curves for
Gravitational-Wave Experiments* (DOI: 10.5281/zenodo.3689582), is published
under the Creative Commons Attribution 4.0 International license
(CC-BY-4.0), verified on the record page on 2026-08-25.  CC-BY-4.0 permits
redistribution with attribution.  Attribution is provided in `README.md`
(data product, associated paper, and method references) and in the
manuscript's citations.  This file is redistributed under CC-BY-4.0, not
under the repository's software license.

## `Figures_3_and_4_PICurve_Design.dat` — public data product, no explicit license

The source, LIGO-T1900058-v3 (<https://dcc.ligo.org/LIGO-T1900058/public>),
is a public LIGO DCC data release accompanying the published O2 isotropic
stochastic-background analysis (Phys. Rev. D 100, 061101).  The public
record page was reviewed on 2026-08-25: the document is publicly
distributed, but no explicit license or terms-of-use statement accompanies
it.  The file is redistributed here verbatim, with full provenance, source
URL, retrieval date, and SHA-256 hash recorded in `README.md`, and with the
associated paper cited in the manuscript.  Users who require a definitive
license should obtain the file from the official DCC URL, which remains the
authoritative source.  This copy will be removed on request of the LIGO
Laboratory or the LIGO Scientific Collaboration.

## `cosmic_explorer_strain_T2000017-v9.txt` — public data product, no explicit license

The source, CE-T2000017-v9
(<https://dcc.cosmicexplorer.org/CE-T2000017/public>), is a public Cosmic
Explorer DCC data release.  On 2026-08-25 the version-pinned archive
`ce_sensitivity.zip` was re-downloaded from the official DCC; the extracted
`cosmic_explorer_strain.txt` matched the SHA-256 recorded in `README.md`
(`ebc9145d…`), confirming the local copy is byte-identical to the official
distribution.  Neither the archive's `README.txt` nor the record page states
an explicit license.  The file is redistributed here verbatim with full
provenance and citation of Kuns et al.; the official DCC URL remains the
authoritative source, and this copy will be removed on request of the Cosmic
Explorer project.

## Scope

These three data files are third-party data products and are excluded from
the repository's software license.  All other detector context curves used
by the figures (LISA, muAres) are computed analytically from published
prescriptions and involve no redistributed data.
